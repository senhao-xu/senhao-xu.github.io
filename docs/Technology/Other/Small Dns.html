SmallDNS ​

前言 ​

小巧轻量的dns服务器，支持正则域名解析IP，正则ip反向解析域名,支持内网解析，公网解析 ，由于small-dns在github上没有找到相关开源信息，只有对应的镜像地址small-dns.

搭建 ​

在dockerhub上作者提供了三种启动方式docker、docker-compose、kubernetes,本文使用kubernetes方式启动。

经测试官方文档的文件挂载路径错误，需添加/app进行纠正

small-dns.yaml

yaml
apiVersion: v1
kind: Namespace
metadata:
  name: dns
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: dns
  namespace: dns
data:
  config.json: |
    [
      {
        "type": "Ptr",
        "names": [
          "127.0.0.1",
          "192\\.\\d{1,3}\\.\\d{1,3}\\.\\d{1,3}",
          "10.43.53.53"
        ],
        "ttl": 600,
        "values": [
          "www.lhstack.com",
          "www.lhstack.cm",
          "lhstack.com"
        ]
      },
      {
        "type":"Ipv4",
        "names":[
          "www.github.com",
          "github.com",
          "github.lhstack.com"
        ],
        "ttl":600,
        "values":[
          "20.205.243.166",
          "140.82.112.4",
          "140.82.114.4",
          "140.82.121.4",
          "52.69.186.44",
          "52.78.231.108",
          "20.248.137.48"
        ],
        "ordered": 2
      },
      {
        "type":"Ipv4",
        "names":[
          "my.domain.com"
        ],
        "ttl":600,
        "values":[
          "127.0.0.1"
        ],
        "ordered": 2
      }
    ]
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: small-dns-env
  namespace: dns
data:
  DNS_LISTEN_ADDRESS: ":53"
  DNS_REPO_TYPE: HighLevelLocal
  HIGH_LEVEL_LOCAL_DNS_RESOLVE_CONFIG: "/app/config/config.json"
  DNS_REMOTE_RESOLVE_ADDRESS: "114.114.114.114:53,8.8.8.8:53"
  HIGH_LEVEL_LOCAL_DNS_RESOLVE_CONFIG_CHECK_INTERVAL_SECONDS: "60"
---
apiVersion: v1
kind: Pod
metadata:
  name: dns
  namespace: dns
  labels:
    app: dns
spec:
  containers:
    - name: small-dns
      image: lhstack/small-dns
      imagePullPolicy: IfNotPresent
      ports:
        - name: udp
          containerPort: 53
          protocol: UDP
          hostPort: 53
      envFrom:
        - configMapRef:
            name: small-dns-env
      volumeMounts:
        - name: config
          mountPath: /app/config/config.json
          subPath: config.json
      resources:
        requests:
          cpu: 20m
          memory: 8Mi
          ephemeral-storage: 5Mi
        limits:
          cpu: 20m
          memory: 16Mi
          ephemeral-storage: 10Mi
  volumes:
    - name: config
      configMap:
        name: dns
        items:
          - key: config.json
            path: config.json
---
apiVersion: v1
kind: Service
metadata:
  name: dns
  namespace: dns
spec:
  type: ClusterIP
  ports:
    - name: udp
      port: 53
      protocol: UDP
  selector:
    app: dns
# clusterIP: 10.43.53.53
bash
#启动
kubectl apply -f small-dns.yaml
#停止
kubectl delete -f small-dns.yaml
#查看服务
kubectl get pod -A | grep dns
#查看日志
kubectl logs -f -n dns dns
#进入容器
kubectl exec -it -n dns dns -- sh

配置 ​

dns配置信息路径为/app/config/config.json文件，支持Ipv4|Ptr,添加域名解析时，配置一组Ipv4信息,修改对应的names及values元素即可。注意格式

json
[
      {
        "type":"Ipv4",
        "names":[
          "my.domain.com",
          "m.domain.com"
        ],
        "ttl":600,
        "values":[
          "127.0.0.1",
          "127.0.0.2"
        ],
        "ordered": 2
      }
]

测试 ​

nslookup [域名] [dns服务器]

bash
#下载nslookup命令
$ yum -y install bind-utils
#nslookup Ipv4测试  
$ nslookup my.domain.com 127.0.0.1
Server:		10.96.0.10
Address:	10.96.0.10:53

Name:	my.domain.com
Address: 127.0.0.1

#nslookup ptr测试
$ nslookup -q=ptr 192.168.2.188 192.168.2.188

内网使用时需将使用机dns指向改dns地址，使用nslookup进行测试。
